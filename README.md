Student Performance Analytics System
Project Overview:
The Student Performance Analytics System is a Python project that processes student academic data and presents useful performance information. It uses a CSV dataset and Python data-analysis libraries to calculate marks, grade points, SGPA, pass/fail results, and class and subject statistics.
Objectives:
Organize student records in a structured format.
Calculate total marks and grade points.
Calculate SGPA using the project's grading rules.
Identify pass/fail results.
Analyze class and subject performance.
Identify top-performing students.
Save processed results to a report file.

Dataset
The input file is students.csv. It contains records for 20 students, including student details, branch, year, attendance percentage, and marks in five subjects:

Grading and Result Rules
The project converts subject marks from a 0–10 scale to a 0–100 scale when applying the chosen grade-point rules:

For pass/fail checking, a subject mark below 4 out of 10 is treated as a fail. Missing or non-numeric subject values may be treated as absent, depending on the final code.
SGPA is calculated as the average of the five subject grade points, assuming all subjects have equal credits.

How to Run:
Install Python on your computer.
Open the project folder in Visual Studio Code.
Install the required libraries if they are not already installed:
py -m pip install pandas numpy
Make sure main.py and students.csv are in the expected project location.
Open the terminal in the project folder and run:
py main.py
Review the terminal output. If the program completes successfully, check for student_performance_report.csv.
